    진행 방식

    수동은 Ctrl+Alt+←/→ 로 넘깁니다.

    아이콘

    단계 옆에 유닛·건물 그림을 함께 보여줍니다.

    그림 파일

    크기 는 창 전체를, 단계 글자 는 빌드 목록만 키웁니다. 목록만 키우면 창 폭은 그대로라 긴 단계가 … 로 잘리니, 그때 가로 폭 으로 넓히세요.

    위치

    직접 끌려면 Ctrl+Alt+L 로 잠금 해제 후 헤더를 드래그.

    효과음

    소리 기본 내장음

    자동 모드에서 단계가 넘어갈 때만 울립니다. 짧은 소리가 좋습니다 — WAV · MP3 · OGG · M4A · FLAC, 5MB 까지.

    설정

    게임에 들어가면 SC2 가 알려주는 플레이어 이름이 여기 표시됩니다.

    매치업 자동 선택용.

    핫키
    • Ctrl+Alt+S시작 / 정지
    • Ctrl+Alt+1~9슬롯 빌드 불러오기
    • Ctrl+Alt+O오버레이 표시 / 숨김
    • Ctrl+Alt+L잠금 해제 (끌어서 이동)
    • Ctrl+Alt+M자동 / 수동 모드
    • Ctrl+Alt+←/→수동으로 단계 이동
    • Ctrl+Alt+C이 제어창 열기
    • Ctrl+Alt+E빌드오더 편집기
    • Ctrl+Alt+R빌드 다시 읽기
    • Ctrl+Alt+Q앱 종료
